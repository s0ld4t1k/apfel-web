# FM AI

Локальный веб-чат для Apple Foundation Model. Интерфейс работает в браузере, а ответы генерируются локально через `fm`.

## Требования

- macOS с доступным Apple Foundation Model;
- установленная команда `fm`;
- `python3` и `curl`.

Проверить установку `fm` можно так:

```bash
fm --help
```

## Запуск

В корне проекта выполните:

```bash
chmod +x start.sh
./start.sh
```

Скрипт:

1. запускает API `fm` на `http://127.0.0.1:11434`;
2. запускает веб-сервер на `http://127.0.0.1:8765`;
3. ждёт готовности API.

Откройте в браузере:

<http://127.0.0.1:8765>

Если `fm` уже запущен на порту `11434`, скрипт использует его.

## Использование

- введите сообщение в поле снизу и нажмите `Enter` или кнопку `↑`;
- используйте `Shift+Enter`, чтобы добавить новую строку;
- кнопка `■` останавливает генерацию ответа;
- `↓ Latest` возвращает к последнему сообщению;
- кнопка `⌫` очищает текущий диалог;
- Markdown в ответах отображается автоматически, код можно скопировать кнопкой `Copy`.

История диалога хранится только в памяти открытой страницы и исчезает после очистки или перезагрузки.

## Остановка

В терминале, где запущен `start.sh`, нажмите:

```text
Ctrl+C
```

Скрипт остановит запущенные им процессы.

## Устройство проекта

```text
index.html  — интерфейс чата
start.sh    — запуск API и локального веб-сервера
```
